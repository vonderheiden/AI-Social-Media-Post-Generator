# Product Overview

AI Social Media Post Generator is a web application that transforms simple topic ideas into fully-generated social media posts with AI-generated images.

## Core Features
- Multi-platform post generation (LinkedIn, Facebook, X/Twitter, Instagram)
- AI-powered content creation using OpenRouter API
- Quote extraction from generated posts
- AI image generation with DALL-E integration
- User authentication via Supabase
- Progressive web app with step-by-step workflow

## User Flow
1. User signs up/signs in via Supabase auth
2. Selects target platform (LinkedIn, Facebook, etc.)
3. Provides topic input via three methods:
   - Manual topic entry
   - Pre-defined suggestions
   - Inspirational quotes
4. AI generates platform-specific content
5. User can regenerate or edit content
6. AI creates accompanying images
7. Final post ready for sharing

## Target Platforms
- **LinkedIn**: Professional, insight-driven content with thought leadership focus
- **Facebook**: Casual, personal posts with storytelling and community engagement
- **X (Twitter)**: Short, punchy content under 280 characters
- **Instagram**: Visual-first captions with expressive language and hashtags
