# Social Media Generator

A web app that turns simple ideas into fully-generated LinkedIn posts with AI images.

## Setup

### Supabase Project
- Project: Kiro-social-media-generator
- URL: https://pkibhlyvjtzikvyjmrdm.supabase.co
- Region: us-west-1

### Local Development
1. Open `index.html` in a browser
2. Sign up with email/password
3. Confirm email (check Supabase dashboard for test mode)
4. Sign in

### Deployment
Ready to deploy on Render as a static site.

## Tech Stack
- HTML/CSS/JavaScript
- Supabase Auth
- Render (deployment)
